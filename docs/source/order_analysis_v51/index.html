차수별 기여도 분석

선택한 Order 성분의 에너지 기여율을 RPM별로 계산. 각 차수의 기여도는 해당 RPM의 전체 Spectrum Overall 에너지를 기준으로 계산.
현재 Order Analysis에서 선택한 채널/Order를 기준으로 계산.
기여도(%) = Aᵢ² / Overall² × 100

    7. 오더 주파수 및 최근접 Bin 검증
    
        
      
    
      
    
        계산식
    
        회전 기본주파수 = RPM ÷ 60
    
        N차 오더 주파수 = N × RPM ÷ 60
    
        시험 피크 주파수 = 이론 오더 주파수 ± 피크 검색 범위 안에서 진폭이 가장 큰 주파수
    
        오더 진폭 = 검출된 시험 피크 주파수 ± 합산 범위의 진폭을 합산
    
        주파수 편차 = 시험 피크 주파수 - 이론 오더 주파수
    
        |주파수 편차| ≤ 일치 허용오차이면 "일치"로 판정
