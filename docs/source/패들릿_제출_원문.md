## 게시물 1 · 2026-09-09T07:58
### 진동·소음 시계열 데이터 자동 분석

1. 추진 배경
-진동·소음 시험 시 RPM 센서 데이터 없이 시계열 데이터만 확보되는 경우가 많음
-시험은 100 → 휴식 → 200 → 휴식 → 300 RPM과 같이 Step 방식으로 수행
-현재는 전체 시계열에서 작업자가 RPM별 구간을 수작업으로 확인·추출하고 FFT 및 Order 분석 수행
-반복 작업에 따른 분석 시간 증가 및 작업자별 결과 편차 발생


2. 현 문제점
현재 절차
-전체 시계열 → 사람이 RPM 구간 확인 → 구간별 데이터 추출 → FFT → 주요 성분 확인 → Order 분석
-RPM 구간 수작업 확인
-휴식 구간 수작업 제거
-RPM별 데이터 개별 추출
-동일 작업 반복


3. 자동화 추진 내용
진동·소음 시계열 데이터 기반 RPM Step 자동 구간 분류 및 NVH 분석
시계열 진동/소음 데이터
          ↓
주요 주파수 성분 자동 검출
          ↓
회전 성분 / Order 분석
          ↓
RPM 역추정
          ↓
RPM별 시험구간 자동 분류
          ↓
휴식구간 자동 제거
          ↓
RPM별 데이터 자동 추출
          ↓
FFT / Order 분석 자동화


4. Input / Output
Input	
-진동·소음 시계열 시험 데이터(메타 데이터 포함)
-RPM step 정보(start rpm, end rpm, rpm step, rpm tolerance)
-주파수 분석 정보(sampling rate, fft range, fft line, window, overlap)
-Stable time 정보(3sec)
-오더 분석 정보(order range, major order detection)


Output
-RPM별 진동소음 시계열 데이터
-실제 추정 RPM 및 신뢰도
-RPM별 FFT 결과
-RPM별 주요 Order 결과
-Campbell Diagram
-주요 진동·소음 성분 Summary
