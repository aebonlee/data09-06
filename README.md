## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-06/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(XLSX 쓰기용 SheetJS 도 `vendor/` 에 들어 있어 밖에서 받지 않습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

쓰는 순서: **1. 불러오기**(CSV 선택 또는 화면에 끌어 놓기, 여러 개 가능) → **2. 열 맞추기**(Testlab Neo 내보내기는 자동 — Curve 목록만 확인) → **3. 분석 설정**(추적 오더·피크 검색/합산 범위·소음/진동 표시 단위·피크·에너지 대역) → **4. 결과**(그래프·컬러맵·표, XLSX·CSV 저장) · **경고 로그**.

- Testlab Neo 에서 내보낸 CSV(「Curve 1」 제목 + `Standard\All\…` 머리 정보)는 **그대로 올리면 됩니다.** RPM 은 Dataset name, 위치·방향은 DOF id, 단위는 Y axis unit 에서 읽고, 원본이 dB 인 소음 채널은 20 µPa 기준으로 Pa 로 바꿔 계산합니다. 파일 이름에 `36,45order` 가 있으면 추적 오더를 36, 45 로 채웁니다.
- 오더 진폭은 제출자 분석기 v34 와 같은 식입니다: 이론 주파수(오더 × RPM ÷ 60) ± 피크 검색 범위에서 가장 큰 칸 → 그 피크 ± 합산 범위 칸들의 RSS. 오더를 두 개 이상 적으면 오더 RSS 합산도 나옵니다.
- 처음 써 볼 때는 **「Testlab 형식 예시 불러오기」**(실제 내보내기와 같은 배치의 가상 파일) 또는 **「예시 데이터 불러오기」**(세로형 가상 런업, 불량 행 2개 포함)를 누르세요. 화면 위에 「예시 데이터」 안내 띠가 표시됩니다.
- **XLSX 통합 문서** 는 v34 「Order Analysis XLSX 저장」 과 같은 시트·열(Settings · Order Analysis · Order RSS Sum)에 이 도구의 표(오더별 최대 · 피크 목록 · 에너지 합산 · 경고 로그)를 시트로 더한 한 파일입니다. v34 는 고른 채널만 담지만 이 도구는 모든 채널·방향을 담습니다.
- 파일 여러 개를 한 번에 고르거나 끌어 놓으면 「불러온 파일」 목록이 생기고, 목록에서 골라 하나씩 바꿔 봅니다(한 그래프에 겹치는 비교는 2단계).
- 분석 설정은 바꾸면 **0.3초 뒤 저절로 다시 계산**합니다. 끄려면 「설정을 바꾸면 바로 다시 계산」 체크를 풀고 「다시 계산」을 누르세요. 칸(주파수 × RPM × 채널)이 150만 개를 넘는 큰 파일이거나 한 번 계산이 1초를 넘으면 저절로 꺼집니다.
- 그래프·컬러맵 위의 **축 범위** 칸(빈칸 = 자동)으로 확대하고, 「자동 범위로」 로 되돌립니다. 그래프 아래 손잡이를 **끌어서 높이**를 바꾸며(위·아래 화살표 20px, 두 번 누르면 기본), 높이는 이 브라우저에 기억합니다.
- 시험 데이터는 **이 브라우저 메모리에서만** 처리하며 어디로도 보내지 않습니다. 이 브라우저에는 분석 설정·마지막 열 매핑·화면 설정(그래프 높이, 즉시 다시 계산)만 기억합니다(시험 데이터는 저장하지 않음).
- 예시 파일(모두 가상): `samples/예시데이터_TestlabNeo형식.csv`(실제 내보내기 배치) · `예시데이터_세로형.csv` · `예시데이터_가로형.csv` · `예시데이터_가로형_열RPM.csv`. 실제 파일 두 개는 200 KB 가 넘어 `docs/source/` 에만 둡니다.
- 로직 테스트: `node test/logic.test.mjs` (설치 없음) — 실제 파일 2종을 읽고, 제출자 v34 의 계산 함수(`docs/source/order_analysis_v34.html`)와 결과·XLSX 행을 맞대 보며, XLSX 는 `vendor/` 의 SheetJS 로 쓰고 다시 읽어 봅니다
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 지금 도구에 들어감, 다음 단계 = 기획서 8장 2단계. 「3차」 는 2026-09-29 에 v34 에서 옮겨 온 기능입니다.

| 기능 (기획서 5장) | 상태 | 한 것 / 남은 것 |
|---|---|---|
| CSV 불러오기·형식 검사 | 완료 | **Testlab Neo 내보내기 자동 인식**(머리 정보 블록, 공통 주파수 축 또는 Curve별 X/Y 열, BOM·지수 표기·`,,,,` 줄), 그 밖에 세로형·가로형·가로형(열=RPM)과 열 매핑, 구분자·소수점 쉼표·천 단위 쉼표, UTF-8/CP949. RPM·위치·방향 못 읽음, 빠진 RPM, 숫자 아님, 주파수 순서, 중복, 단위 불일치를 원본 줄 번호와 함께 경고 로그에 기록 |
| 채널·방향 선택 | 완료 | 위치·방향(소음은 위치만)별 선택 + 다른 채널 겹쳐 보기 |
| 오더 변환·오더 추적 | 완료 (v34 기준) | 이론 주파수 ± 피크 검색 범위(Hz) → 검출 피크 ± 합산 범위(Hz) RSS, 판정 일치/불일치. 회전비 설정(기본 1). 1차의 오더 대역 최대값·RSS 방식도 선택 가능 |
| 오더 RSS 합산 | 완료 (v34 기준) | 오더 2개 이상이면 같은 RPM 의 오더 진폭 RSS — 그래프 점선·표·CSV |
| 단위 변환·dB 표시 | 완료 (v34 기준) | 소음·진동 따로 Amplitude / dB / dBA, dB 기준값, 원본 dB·dBA 입력 → 선형 변환. 컬러맵도 같은 단위 |
| 피크 추출 | 완료 | RPM 별 국소 최대 피크 상위 N개 (v34 에는 없음 — 이 도구가 더함) |
| 에너지 합산 | 완료 | 지정 대역(Hz·오더) RSS (v34 에는 없음 — 이 도구가 더함) |
| 스펙트럼 컬러맵 | 완료 | RPM × 주파수 / 오더, 가로축·색 범위 입력, 추적 오더 선(nX), 피크 표시 |
| 피크 정보 툴팁 | 완료 | 그래프: 이론·검출 피크 주파수·합산 범위·판정 / 컬러맵: 칸 값, 피크, 오더 선 근처는 그 오더의 검색 범위·검출 피크 |
| 결과 CSV 저장 | 완료 | 오더 추적(v34 Order Analysis 와 같은 열)·오더 RSS 합산·오더별 최대·피크 목록·에너지 합산 (UTF-8 BOM) |
| 오류·경고 로그 저장 | 완료 | 화면 표와 CSV |
| XLSX 저장 | 완료 (3차) | v34 와 같은 시트·열(Settings·Order Analysis·Order RSS Sum — RSS 는 오더 2개 이상일 때만) + 오더별 최대·피크 목록·에너지 합산·경고 로그 시트. 값은 반올림하지 않은 숫자, Curve 번호 포함. SheetJS 를 `vendor/` 에 두고 처음 저장할 때 불러옴 |
| 그래프 축 범위 | 완료 (3차) | RPM-진폭 그래프 RPM·진폭 최소/최대, 컬러맵 가로축·RPM·색 범위, 빈칸 = 자동(자리에 자동값 표시), 최소 ≥ 최대면 자동, 「자동 범위로」, 범위 밖은 잘라 냄 |
| 그래프 크기 조절 | 완료 (3차) | 그래프·컬러맵 아래 손잡이를 끌어 높이 240~900 px(화살표 키·두 번 눌러 기본), 브라우저에 기억. 가로는 화면 폭에 맞춰 다시 그림 |
| 끌어 놓기 업로드 | 완료 (3차) | 화면 어디에 놓아도 받음, 여러 파일 → 「불러온 파일」 목록, CSV·TXT 가 아닌 파일은 뺌. 파일 선택도 여러 개 |
| 설정 즉시 다시 계산 | 완료 (3차) | 0.3초 뒤 계산, 틀린 값은 계산하지 않고 이유 표시, 끌 수 있음(기억), 큰 파일(칸 150만 초과)·1초 넘는 계산은 저절로 끔 |
| 다크 모드 | 다음 단계 | v34 에 있음 — 계산과 무관 |
| 여러 시험 비교 | 다음 단계 | 2단계 |

v34 와의 비교·계산 차이는 [개발일지 2차](docs/개발일지.md), v34 화면 기능을 옮긴 내용은 개발일지 3차에 정리했습니다.
