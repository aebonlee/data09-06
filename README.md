## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-06/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(외부 라이브러리를 쓰지 않습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

쓰는 순서: **1. 불러오기**(CSV 선택) → **2. 열 맞추기**(배치·열 지정, 미리 보기 확인) → **3. 분석 설정**(추적 오더·대역·피크·에너지 대역) → **4. 결과**(그래프·컬러맵·표, CSV 저장) · **경고 로그**.

- 처음 써 볼 때는 **「예시 데이터 불러오기」** 를 누르세요. 가상 엔진 런업 데이터가 들어가고 화면 위에 「예시 데이터」 안내 띠가 표시됩니다. 형식 검사를 보여 주려고 불량 행 2개를 일부러 넣었습니다.
- 시험 데이터는 **이 브라우저 메모리에서만** 처리하며 어디로도 보내지 않습니다. 이 브라우저에는 분석 설정과 마지막 열 매핑만 기억합니다(시험 데이터는 저장하지 않음).
- 예시 파일(모두 가상): `samples/예시데이터_세로형.csv` · `예시데이터_가로형.csv` · `예시데이터_가로형_열RPM.csv`. 열 제목(RPM, Channel …)과 단위(g)는 가정이며 실제 Testlab Neo 내보내기와 다를 수 있습니다.
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 이번 1단계 도구에 들어감, 다음 단계 = 기획서 8장 2단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| CSV 불러오기·형식 검사 | 완료 | 구분자(쉼표·세미콜론·탭)·소수점 쉼표·머리행 자동 짐작(Testlab 머리 정보 줄 건너뜀), UTF-8/CP949 읽기, 배치 3종(세로형·가로형·가로형 열=RPM) 선택과 열 매핑, 빈 값·숫자 아님·RPM 0 이하·중복 주파수/RPM·단위 불일치를 원본 줄 번호와 함께 경고 로그에 기록 |
| 채널·방향 선택 | 완료 | 채널·방향별 그룹으로 나눠 선택. 파일에 채널·방향·단위 열이 없으면 직접 적은 값 사용 |
| 오더 변환 | 완료 | 오더 = 주파수 × 60 ÷ (RPM × 회전비). 회전비(기어비)는 설정값, 기본 1 |
| 오더 추적 | 완료 | 추적 오더 여러 개(쉼표), 오더 대역 반폭(±), 대역 최대값 또는 대역 RSS 선택 → 오더별 RPM-진폭 그래프·오더별 최대 표. 대역에 주파수 칸이 없으면 경고 |
| 피크 추출 | 완료 | RPM 별 국소 최대 피크 상위 N개(주파수·오더·진폭), 최소 진폭 기준 설정 |
| 에너지 합산 | 완료(가정) | 지정 대역(Hz 또는 오더, 빈칸=전체)의 제곱합의 제곱근(RSS). 합산 방식은 제출자 기준 확인 필요(기획서 10장 6번) |
| 스펙트럼 컬러맵 | 완료 | RPM × 주파수 / RPM × 오더 전환, 색 막대(선형), 피크 위치 표시 |
| 피크 정보 툴팁 | 완료 | 그래프·컬러맵에 마우스를 올리거나 누르면 RPM·주파수·오더·진폭(피크면 순위) 표시 |
| 결과 CSV 저장 | 완료 | 오더 추적·오더별 최대·피크 목록·에너지 합산 CSV(모든 채널·방향, UTF-8 BOM) |
| 오류·경고 로그 저장 | 완료 | 가져오기·분석 경고를 화면 표와 CSV 로 저장 |
| 단위 변환·dB 표시 | 다음 단계 | 2단계 (지금은 선형 진폭만) |
| 여러 시험 비교 | 다음 단계 | 2단계 |

> 제출자가 메일로 보냈다는 초안 HTML과 예시 CSV는 아직 받지 못해, 기획서 명세와 가상 샘플로 만들었습니다. 받으면 실제 열 배치·계산 기준을 초안과 맞춰 봅니다.
